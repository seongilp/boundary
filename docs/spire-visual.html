전체 zero-trust 그림

LDAP → Keycloak(SSO)
→ Boundary(RBAC)
→ SSH/DB/k8s
서비스 → 서비스
SPIRE(SVID)
→ mTLS / Vault 인증
→ 동적 자격증명
공통 원칙: 신원 기반 + 단기 자격증명 + 시크릿 제로. 사람이든 서비스든 "장수명 비밀번호"를 없앤다.
